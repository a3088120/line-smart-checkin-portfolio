# 技術亮點

每項以「實際問題 → 技術解法 → 應用價值」說明，並區分已驗證成效與預期效益。實作存在不等於正式環境已驗收。

## 1. 不固定工作地點的定位驗證

**實際問題**：員工可能在不同據點出勤；固定單一座標不適用。無效座標、沒有啟用地點或超出允許距離時，也不能寫成成功打卡。

**技術解法**：n8n 從工作地點表讀取可用地點，依事件座標計算距離，選出符合條件的最近地點並和該地點允許距離比較。GAS 另提供地址 Geocoding，API Key 由伺服器端 Script Properties 讀取。

**應用價值**：讓地點可由資料表管理，打卡判斷可依多據點設定執行；無效地點或超距路徑不進入成功寫入。

**驗證界線**：Workflow、距離程式及 GAS 地理編碼程式已存在；合成資料測試涵蓋沒有啟用地點及距離情境。各正式據點座標、距離設定及正式環境端到端驗證不在本次證據範圍內。預期效益為減少地點規則寫死於程式的維護需求，未量測工時或改善百分比。

## 2. 上下班與重複打卡判斷

**實際問題**：單看當日第幾次打卡，可能把遲到、漏打或下班後重複事件判錯；重複下班資料也可能覆蓋正式下班時間。

**技術解法**：Code Node 依班別允許時段和同一員工當日既有成功紀錄共同決定上下班類型。重複次數只用於限制下班後的異常寫入；達上限後拒絕新增。主管結果整理另依異常原因排除重複下班，保留正式紀錄時間。

**應用價值**：打卡分類依業務狀態而非事件先後次數，並降低重複事件污染正式上下班紀錄的風險。

**驗證界線**：Workflow、JavaScript 與合成測試已涵蓋正常、遲到、拒絕時段及重複下班限制；正式環境全時段與所有重複事件回歸尚未完成。預期效益是提升資料一致性，未有錯誤率或節省工時的量化數據。

## 3. 主管查詢及權限驗證

**實際問題**：出勤資料含員工個資，不能只憑查詢文字或姓名讓使用者取得資料。

**技術解法**：主管查詢 Workflow 以 LINE userId 比對主管表中啟用的帳號；驗證不通過就走權限拒絕分支。LIFF 管理 API 由 GAS 再驗證 LINE ID Token 及後端角色／組別，之後才讀寫 Google Sheets。主管查詢結果亦以使用者識別與日期配對照片，不以姓名猜測歸屬。

**應用價值**：將使用者驗證放在資料讀取之前，管理 API 亦有後端授權檢查，降低單靠前端控制存取的風險。

**驗證界線**：n8n 與 GAS 對應程式已存在，主管結果有合成資料測試；主管各角色、日期及拒絕情境的完整實機驗證仍待完成。不能據此宣稱已通過正式資安稽核。

## 4. 照片打卡與異常處理

**實際問題**：定位、照片下載、Drive 上傳與正式打卡寫入是多步驟操作。重複事件或外部服務失敗可能造成照片錯配、重複寫入或回覆成功但資料不完整。

**技術解法**：Workflow 以待完成打卡紀錄、員工／日期配對與 90 秒期限管理照片流程；並拆分照片下載、Drive 上傳、正式紀錄存在性檢查、暫存狀態更新及 LINE 回覆。失敗與異常分支保留追蹤路徑。

**應用價值**：把跨服務流程的中間狀態明確化，讓照片配對、重試與正式紀錄寫入可分別追蹤。

**已驗證成效**：測試紀錄於 2026-10-07 至 10-08 記載未定位直接傳照片、期限內重複定位、90 秒內正常照片打卡、照片逾時及逾時後重新定位等案例實機通過。

**尚待驗證**：照片下載／上傳失敗、重複照片、資料衝突、正式寫入失敗及完整規則回歸仍未全部完成。因此上述通過案例不能代表整個照片打卡流程已驗收。預期價值是降低狀態不一致風險；沒有量化成效數據。

## 5. Cloudflare Pages／LINE LIFF 整合

**實際問題**：LINE LIFF 管理介面需要 HTTPS 前端及後端資料存取；共享密鑰不能暴露在瀏覽器，角色權限也不能只靠前端頁面控制。

**技術解法**：Cloudflare Pages 託管 LIFF 前端，Pages Function 提供同源 API 閘道，檢查請求來源、大小、格式及允許操作，再用伺服器端 Secret 呼叫 GAS。GAS 比對共享密鑰、向 LINE 驗證 ID Token、核定角色／組別後才讀寫 Google Sheets。地址 Geocoding 由 GAS 伺服器端呼叫。

**應用價值**：前端不持有 Pages 與 GAS 間的共享密鑰；將網域請求檢查與資料授權分置於閘道和後端，建立明確的服務邊界。

**已驗證成效**：專案紀錄記載曾透過 LINE 完成身分驗證，Pages 至 GAS 呼叫並讀取管理資料成功。

**尚待驗證**：員工姓名／狀態及工作地點新增修改仍待實際寫入驗證；本次未連接 Cloudflare 或 GAS 核驗現在部署狀態。預期價值為集中管理 API 與權限檢查，未有效能或成本量化結果。
