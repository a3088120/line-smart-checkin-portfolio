## 狀態定義

- **已實作**：目前本機程式或 Workflow 可找到對應節點／程式碼，不代表已部署或已驗收。
- **已實測**：文件有實際測試結果或明確的合成資料測試記錄；僅適用該案例與環境。
- **開發中**：已有部分實作，但必要情境、整合或回歸測試未完成。
- **規劃中**：Roadmap 列出方向，目前來源檔案沒有足以證明功能已實作的內容。
